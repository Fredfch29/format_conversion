# JSONL to Excel Converter

将 JSONL 文件转换为 Excel (.xlsx) 格式的 Python 脚本。

## 安装依赖

```bash
pip install -r requirements.txt

使用方法
1. 打开 jsonl_to_excel.py，修改顶部的文件名：
input_file = "input.jsonl"       # ← 修改为你的 JSONL 文件名
output_file = "output.xlsx"      # ← 修改为你想要的 Excel 输出文件名

2. 运行脚本：
python jsonl_to_excel.py
